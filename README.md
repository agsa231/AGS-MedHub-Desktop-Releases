# AGS MedHub Desktop Downloads

This public repository is reserved for official Windows/macOS installer binaries, SHA-256 checksum files, release notes, and installation instructions. It contains no AGS MedHub application source code.

## Downloads

No installer release is published yet. Direct download links will be added after the release candidate passes the remaining acceptance gates and the owner approves publication. Do not install or redistribute a private Actions artifact.

## Unsigned installer guidance

The approved release plan is for unsigned installers. Windows may show SmartScreen, and macOS may show Gatekeeper warnings. Before installation, download only from an official AGS MedHub release link and verify the matching SHA-256 checksum. If the operating system offers a per-app confirmation after verification, use its documented app-specific option. Do not disable antivirus, Gatekeeper, or operating-system protections globally.

## Planned platform targets

- Windows 10/11, x64, NSIS `.exe`
- macOS Apple Silicon, `.dmg`
